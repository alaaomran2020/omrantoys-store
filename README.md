# 🧸 متجر عمران للألعاب | Omran Toys Store

متجر إلكتروني متكامل وعصري متخصص في ألعاب الأطفال التعليمية والترفيهية، مبني بأحدث تقنيات الويب (React 19 + Vite + Tailwind CSS + Lucide Icons).

---

## 🌟 مميزات المتجر الرئيسية

### 1. 🛍️ تجربة تسوق تفاعلية وعصرية
- **تصميم مرح ومبهج للأطفال والأولياء**: متجاوب بالكامل 100% مع الهواتف الذكية والأجهزة اللوحية والشاشات الكبيرة.
- **دعم اللغة العربية والاتجاه من اليمين لليسار (RTL)** مع خط كوفي/عصري أنيق (Cairo & Tajawal).
- **بحث فوري ذكي مع اقتراحات مباشرة (Instant Live Search)**: إمكانية البحث الفوري بالاسم، الوصف، الماركة، أو الكلمات الدلالية.
- **تصفية متقدمة (Smart Filtering)**:
  - تصفية حسب الأقسام (تعليمية وذكاء، مكعبات وبناء، سيارات تحكم، دمى ومجسمات، ألعاب لوحية، ألعاب خارجية، رضع، فنون وصلصال).
  - تصفية حسب الفئة العمرية (0-2، 3-5، 6-8، 9-12، 12+ سنة).
  - شريط تمرير الميزانية وتحديد أقصى سعر.
  - فرز حسب: المقترح، الأكثر مبيعاً، السعر، التقييم، والأحدث.

### 2. 🎁 مستكشف الهدايا الذكي (Smart Gift Finder)
- معالج تفاعلي من 3 خطوات يساعد الأهل والأقارب على اختيار الهدية المثالية للطفل حسب:
  1. عمر الطفل
  2. اهتماماته وشغفه
  3. الميزانية المحددة
- عرض فوري للهدايا المرشحة مع إمكانية إضافتها للسلة وتفعيل خيار التغليف بضغطة زر واحدة.

### 3. 🎀 تغليف هدايا فاخر وبطاقات إهداء مجانية
- إمكانية طلب تغليف هدية فاخر مجاناً لكل منتج في السلة.
- كتابة رسالة إهداء مخصصة للطفل تطبع على بطاقة أنيقة مرافقة للشحنة.

### 4. 🛒 سلة تسوق ذكية ونظام الكوبونات
- مؤشر تفاعلي للشحن المجاني (شحن مجاني للطلبات فوق 250 ريال).
- دعم كوبونات الخصم الترويجية:
  - `OMRAN10`: خصم 10% ترحيبي
  - `TOYS20`: خصم 20% للطلبات فوق 250 ريال
  - `FREESHIP`: شحن مجاني فوري
  - `EID2026`: خصم 15% لموسم الأعياد
- حساب المجموع والخصم وتكلفة الشحن وضريبة القيمة المضافة (15% VAT).

### 5. 💳 إتمام طلب فوري ومتعدد وسائل الدفع
- إدخال بيانات التوصيل والعنوان التفصيلي في مختلف مدن المملكة والخليج.
- دعم خيارات دفع متعددة:
  - بطاقة مدى / فيزا / ماستركارد
  - Apple Pay
  - تمارا (تقسيط على 4 دفعات بدون فوائد)
  - تابي (تقسيط ميسر)
  - الدفع عند الاستلام (COD)
- تأثيرات احتفالية (Confetti) عند إتمام الطلب بنجاح.
- توليد رقم طلب فريد وإمكانية المتابعة الفورية مع فريق المتجر عبر واتساب أو طباعة الفاتورة.

### 6. 📦 نظام تتبع الشحنات والطلبات (Order Tracking)
- تتبع حالة الطلب برقم الطلب (مثال: `OMR-8842`) أو رقم الجوال.
- مخطط زمني تفاعلي لمراحل الطلب:
  - تم استلام وتأكيد الطلب
  - التجهيز وتغليف الهدايا 🎁
  - تم التسليم لشركة الشحن 🚚
  - تم التوصيل واستلام الهدية بنجاح

### 7. ⚙️ لوحة إدارة المتجر (Admin Dashboard)
- إحصائيات حية: إجمالي المبيعات، عدد الطلبات، عدد المنتجات، وتنبيهات نفاد المخزون.
- إضافة ألعاب جديدة للمتجر بنموذج متكامل (الاسم، السعر، الخصم، المخزون، العمر، الصورة، الوصف).
- تعديل الأسعار وكميات المخزون مباشرة.
- إدارة وتحديث حالات الطلبات الواردة (قيد الانتظار، قيد التجهيز، تم الشحن، تم التوصيل).
- حفظ دائم في التخزين المحلي (LocalStorage).

### 8. 💱 دعم متعدد العملات
- ريال سعودي (ر.س)
- درهم إماراتي (د.إ)
- دولار أمريكي ($)
- دينار كويتي (د.ك)
- جنيه مصري (ج.م)

## 🚀 تشغيل المشروع محلياً

```bash
# تثبيت الحزم
npm install

# تشغيل خادم التطوير
npm run dev

# بناء النسخة الإنتاجية
npm run build

# معاينة النسخة الإنتاجية
npm run preview
```
